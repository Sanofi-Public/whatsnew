renv Lock File Comparison

Overview

The renv lock comparison workflow compares two renv lock files, identifies package version differences, runs compare_package_versions for each changed package, and produces a risk assessment report with dependency and function changes.

Running the Comparison

library(whatsnew)

Source the comparison script and run it. Uses defaults when called with no arguments (lock files from package, output to tempdir()):

source(system.file("script/compare_renv_lock.R", package = "whatsnew"))
compare_renv_lock_files()  # Uses default lock files and tempdir() for output

# Or with explicit paths:
compare_renv_lock_files(
  lock_old = system.file("env/renv_Rforsub_old.lock", package = "whatsnew"),
  lock_new = system.file("env/renv_Rforsub.lock", package = "whatsnew"),
  result_path = tempdir()
)

Note: compare_renv_lock_files() downloads package metadata from CRAN via compare_package_versions(). Run the above in an interactive session when network access is available.

Output Files

The comparison writes to result_path/renv_lock_comparison/:

  • report.md – full Markdown report (shown above)
  • risk_report.json – structured risk assessment
  • package_reports/*.qmd – QMD file per package
  • json/*.json – full diff JSON per package
